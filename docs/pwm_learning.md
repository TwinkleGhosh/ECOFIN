# PWM Learning Notes

## What is PWM?

PWM (Pulse Width Modulation) is a signal control technique used to regulate :
- motor speed
- ESC behavior
- thruster output
- servo positioning

---

## Why PWM is Important

PWM acts as the communication layer between:
- microcontroller
- ESC
- thrusters

Without PWM:
- motor control is not possible
- speed regulation cannot occur
- directional thrust cannot be managed

---

## ESC Signal Standards

Typical PWM ranges:
- 1000us = minimum throttle
- 1500us = neutral
- 2000us = maximum throttle
