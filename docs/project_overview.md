# EcoFin Project Overview

## Introduction

EcoFin is a thruster-based underwater robotic fish system designed for marine surveillance and environmental monitoring.

The project focuses on:
- underwater navigation
- thruster control systems
- AI-assisted environmental analysis
- modular robotics architecture

Current hardware stage:
- PLA fish body
- underwater thrusters

Future planned integrations:
- ESCs
- microcontroller systems
- IMU sensors
- AI vision systems
- onboard navigation algorithms
- pollution detection modules

---

## Project Objectives

1. Develop stable underwater locomotion
2. Learn robotic control systems
3. Build autonomous navigation architecture
4. Research underwater AI systems
5. Design scalable robotics software
6. Explore marine environmental applications
