# Waypoint Navigation Concepts

## Objective

EcoFin is planned to support waypoint-based autonomous navigation.

---

# Basic Navigation Workflow

1. Detect current position
2. Compare with target waypoint
3. Adjust heading direction
4. Move toward destination

---

# Future Navigation Inputs

Potential sensor systems:
- IMU
- depth sensor
- camera systems

---

# Navigation Challenges

- no GPS underwater
- underwater drift
- changing currents
- visibility limitations

---

# Long-Term Goals

- autonomous path planning
- obstacle avoidance
- environmental mapping
