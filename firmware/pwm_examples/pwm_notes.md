# PWM Firmware Notes

## Objective

This firmware section is used to study PWM-based thruster control systems for EcoFin.

---

# Current Learning Areas

- PWM signal generation
- ESC communication
- microsecond pulse control
- thruster speed balancing

---

# Standard PWM Values

| Signal | Meaning |
|--------|---------|
| 1000us | Minimum throttle |
| 1500us | Neutral |
| 2000us | Maximum throttle |

---

# Research Goals

- smooth thrust transitions
- stable movement control
- synchronized thruster output
- efficient underwater propulsion
