# Feedback Systems Research

## Introduction

Feedback systems continuously monitor system behavior and apply corrections.

---

# Open Loop vs Closed Loop

## Open Loop
No automatic correction.

## Closed Loop
Uses sensor feedback for automatic adjustments.

PID systems are closed-loop systems.

---

# Importance in Robotics

Feedback systems help:
- reduce error
- improve accuracy
- stabilize movement
- enable autonomous behavior
