# Thruster Specifications

## Current Thruster Configuration

EcoFin currently uses a 3-thruster propulsion configuration.

Thruster placement:
- Left fin thruster
- Right fin thruster
- Rear tail thruster

This configuration enables:
- forward propulsion
- turning control
- directional stabilization
- differential thrust movement

---

# Thruster Layout

## 1. Left Fin Thruster

Purpose:
- left-side propulsion
- turning assistance
- movement balancing

Position:
- mounted near left fin section

Control Method:
- ESC + PWM

---

## 2. Right Fin Thruster

Purpose:
- right-side propulsion
- directional correction
- stability balancing

Position:
- mounted near right fin section

Control Method:
- ESC + PWM

---

## 3. Rear Tail Thruster

Purpose:
- primary forward propulsion
- thrust generation
- speed control

Position:
- mounted at rear tail fin

Control Method:
- ESC + PWM
