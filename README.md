# EcoFin

EcoFin is a thruster-based underwater robotic fish designed for marine surveillance and environmental monitoring.

The project focuses on underwater navigation, stabilization systems, AI-assisted monitoring, and modular robotic architecture.

---

# Current Development Status

- PLA body acquired
- Thrusters acquired
- Learning embedded systems
- Studying PWM and ESC control
- Building software architecture
- Researching underwater robotics

---

# Planned Features

- Thruster propulsion system
